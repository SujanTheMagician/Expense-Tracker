# 💸 Student Expense Tracker

A personal finance tracker for students, built by **Sujan Anandh** — 3rd Year B.Tech CSE at AMET University & Intern at ATIUM Sports.

## ✨ Features

- **Add expenses** with name, amount, category, and date
- **Monthly budget** with animated color-coded progress bar (green → amber → red)
- **Doughnut chart** (Chart.js) for category spending breakdown
- **Filter** expenses by category or search by name
- **Export to CSV** for spreadsheet analysis
- **Dark mode** toggle with Tailwind `dark:` classes
- **Fully responsive** — works great on mobile
- **localStorage** persistence — data survives refreshes
- **About Me** page — personal portfolio section

## 🛠️ Tech Stack

- React 19 + Vite
- Tailwind CSS v4
- Chart.js
- localStorage for persistence

## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
```

## 🌐 Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **GitHub Actions**
4. The workflow in `.github/workflows/deploy.yml` will auto-deploy on every push to `main`
